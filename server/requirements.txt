#  RANGOS, NO VERSIONES EXACTAS. Y el motivo es concreto: estaban
#  clavadas con == y en una PC con Python 3.14 la instalacion fallaba
#  entera. Ninguna de esas versiones -de finales de 2024- trae ruedas
#  compiladas para 3.14, asi que pip intentaba compilar pydantic-core
#  desde el codigo fuente, eso necesita Rust, y el paso [3/6] del
#  instalador se caia dejando el servidor sin librerias, sin llaves y
#  sin .env. En el diagnostico se veia clarisimo: en el entorno solo
#  estaba pip.
#
#  Con rangos, pip elige en cada computadora la version mas nueva que
#  cumpla, que es la que SI tiene rueda para su Python. El piso de cada
#  rango es la version con la que se probo esto; el techo es la siguiente
#  version mayor, que es donde estas librerias rompen compatibilidad.
#
#  Si algun dia hace falta congelar las versiones exactas de una
#  instalacion que ya funciona:
#
#      .venv\Scripts\python.exe -m pip freeze > requirements-fijas.txt
#
#  y se instala con ese archivo. Pero el de aqui se queda con rangos,
#  porque es el que corre en computadoras ajenas.
